# Generative AI Research Project

## Project Overview
This repository stores and organises research materials for the project "Using Generative AI Tools - Boon or Bane".

## Folder Structure
- 01_Literature_Review: journal articles, conference papers, books, and news articles
- 02_Quantitative_Analysis: survey data, survey questions, scripts, and analysis reports
- 03_Qualitative_Analysis: interview transcripts, protocols, consent forms, insights reports, and visualisations
- 04_Drafts_and_Reports: draft proposals, conference papers, and final reports
- 05_Additional_Materials: information sheets, photos, and media files
- 06_Documentation: supporting documentation

## How to Navigate
Open the folders according to the type of material. File names are organised using clear naming conventions to improve accessibility and version tracking.

## Contribution Guide
1. Pull the latest version of the repository
2. Create a new branch before making changes
3. Commit changes with meaningful commit messages
4. Push the branch and open a pull request
5. Wait for review before merging changes
